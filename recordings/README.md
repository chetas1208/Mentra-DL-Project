# recordings/

voice data — never commit, never push to a public remote.

Suggested layout once collection starts:

```
recordings/
  session01/
    manifest.json
    0001_wearer.wav
    0002_environment.wav
    ...
```

See `docs/DATA_COLLECTION.md` for session/labeling protocol.
