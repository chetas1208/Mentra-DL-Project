# GeoWearNet P1 — Product Audio Evaluation Report

Generated by `evaluation/agent_audio/report.py` from measured artifacts in
`evaluation/agent_audio/results/`. Every number below is computed, not estimated.

**What this measures:** not detector AUROC, but what the voice agent actually
receives — wearer WER/TER, **bystander leakage rate**, wearer deletion, false
agent command rate, latency. See `docs/geowearnet_product_architecture.md`.

**The oracle gate is the load-bearing comparison.** It is the same gate, same
policy, same smoothing, same ASR — fed ground-truth activity instead of
predictions. So `RAW → ORACLE` is everything detection-plus-routing can deliver,
`ORACLE → GEOWEAR` is what is currently lost to detector error, and whatever the
oracle still gets wrong is the routing architecture's own ceiling.
